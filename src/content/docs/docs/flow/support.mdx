For bugs and feature requests, use [Openza Flow GitHub Issues](https://github.com/openza/flow/issues).

For privacy or security-sensitive questions, email [deependra@solanky.dev](mailto:deependra@solanky.dev) instead of posting publicly.

## Agent Sessions

Before reporting a problem:

- Confirm that `codex --version` works in the affected Windows or WSL environment.
- Confirm that Windows Terminal is installed before using **Resume in terminal**.
- Refresh after starting a WSL distribution that has been stopped for a long time.
- Confirm that the original working directory still exists.

Include the Flow version, Windows version, environment type, WSL distribution when relevant, Codex version, and visible error category.

Do not post tokens, OAuth codes, session identifiers, prompts, conversation content, personal paths, private repository information, or unreviewed diagnostic logs.
