title: Openza Flow
description: Agent sessions from Windows and WSL, together in one place.
---

Openza Flow is a local-first Windows companion that brings agent-session history from Windows and WSL together, with optional GitHub activity.

- **Bring agent sessions together** from native Windows and detected WSL distributions.
- **Find the right session** with search, environment filters, and grouping by date or repository.
- **Return to the original environment** by resuming a session in Windows Terminal.
- **Keep GitHub activity close:** review requests, your pull requests, releases, and Actions runs.
- **Choose notifications** for background refresh, only if you want them.

[Install from the Microsoft Store](https://apps.microsoft.com/detail/9N37DN0X68PZ) · [Source on GitHub](https://github.com/openza/flow)
