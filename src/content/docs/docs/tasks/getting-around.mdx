Openza Tasks keeps navigation, projects, your task list, and the selected task's details in one window.

## Lists

The left navigation holds your lists. Each shows open tasks unless noted.

| List | Shows |
| --- | --- |
| **Inbox** | New tasks that have no project yet and still need sorting |
| **Next Actions** | Tasks marked **Next** |
| **Today** | Tasks planned or due today |
| **Calendar** | Dated tasks by day |
| **Overdue** | Planned work and deadlines that have passed |
| **Waiting For** | Tasks you are waiting on someone else for |
| **Someday** | Ideas and tasks for later |
| **Tasks** | Every open task |
| **Completed** | Finished tasks |

**Sync** shows the status of your connected apps, and **Settings** holds appearance, integrations, Spaces, and data options.

## Projects

The projects pane lists the projects in the selected Space. Filter it by name, show active, completed, or archived projects, and sort by name, open task count, or favorites first. Select a project to see its tasks. See [Spaces, projects and labels](/docs/tasks/organize/).

## Task list

Above the list you can:

- **Search** the current list.
- **Filter** by priority, label, or repeating tasks.
- **Sort** by date, priority, title, created, updated, or completed date.
- **Group** by date, project, status, priority, label, source, repeating, created, or completed.

Your filter, sort, and group choices are remembered for each list.

## Task details

Select a task to edit it on the right: title, notes, project, status, date, deadline, priority, and labels. Connected tasks also show where they came from. From here you can complete, delete, copy, or move the task to another Space, and create or open its GitHub issue.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | Add a task |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Search all tasks and projects |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | Search the current list |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | Save the selected task, or sync when no task is selected |
