---
title: GitHub issues
description: Turn an Openza task into a GitHub issue.
---

GitHub is a place to publish tasks to, not a source to import from.

## Connect

Open **Settings > Integrations > GitHub** and select **Sign in with GitHub**. Openza shows a code to enter on GitHub. You can also paste a personal access token instead. Optionally save a default repository, such as `openza/tasks`.

For private repositories, your sign-in or token needs access to private repositories.

## Create an issue

Select a task and choose the GitHub action in task details. Pick the repository, check the title and body, choose labels, and publish.

Openza saves the issue link on the task, and the task stays open. When a task already has an issue, the same action opens it instead, so you do not create duplicates.

Openza does not import GitHub issues or sync their state or comments. Removing the link in Openza never deletes the issue on GitHub.
