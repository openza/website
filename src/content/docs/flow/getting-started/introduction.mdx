title: Openza Flow
description: What Openza Flow does
---

Openza Flow brings agent-session history from native Windows and WSL together in one local-first Windows workspace. The current release supports Codex sessions and keeps useful GitHub activity close when you choose to connect an account.

## What you can do

- **Bring session history together.** Browse agent sessions from native Windows and WSL in one view.
- **Search and group sessions.** Filter locally loaded history by environment and group it by date or repository and folder.
- **Return to the original environment.** Open a supported session in Windows Terminal using its original environment and working directory.
- **See review requests.** View pull requests where your review has been requested.
- **Follow your pull requests.** See pull requests you created and open them on GitHub.
- **Monitor repository activity.** Check recent releases and Actions workflow runs across repositories in the selected organization.
- **Search and filter.** Search pull requests and filter them by organization.
- **Choose background updates.** Turn on tray mode and notifications only if you want Flow to keep checking.

## Get started

1. [Install Flow](/flow/getting-started/installation/).
2. Open Agent Sessions to discover Codex on Windows and WSL.
3. [Connect GitHub](/flow/getting-started/github-token/) only if you want GitHub Activity.

Flow works without GitHub sign-in. It does not install Codex, Windows Terminal, or WSL.
