## Install from Microsoft Store

[Install Openza Flow from the Microsoft Store](https://apps.microsoft.com/detail/9N37DN0X68PZ)

You can also [open the listing in the Microsoft Store app](ms-windows-store://pdp/?ProductId=9N37DN0X68PZ).

The Microsoft Store installs updates automatically and lets you uninstall Flow from Windows Settings.

## Requirements

- Windows 10 version 22H2 or later, or Windows 11
- A 64-bit Windows PC
- A working OpenAI Codex CLI installation on Windows or WSL for Agent Sessions
- Windows Terminal for session resume
- Optional: WSL 2 for Linux-hosted sessions
- Optional: a GitHub account for GitHub Activity

After installation, open **Openza Flow** from the Start menu. Local features do not require an account. [Connect GitHub](/flow/getting-started/github-token/) only if you want GitHub Activity.
