Last updated: July 26, 2026

Openza Flow is a local-first Windows developer companion maintained by Deependra Solanky. Openza does not operate a server that receives information from Flow.

Flow does not send telemetry, analytics, advertising identifiers, crash reports, agent-session content, or GitHub data to Openza.

## Agent Sessions

Flow searches the current Windows user's executable path and installed WSL distributions for a working Codex CLI. It starts the locally installed Codex `app-server` process to request interactive, non-archived session summaries.

Displayed information can include session identifiers, titles, source application, timestamps, working directories, repositories, branches, and a short selected-session preview.

Session summaries and previews remain in memory while the relevant parts of Flow are active. Flow does not upload them, add them to its GitHub cache, or directly read, edit, move, or delete Codex JSONL or SQLite state files.

For Agent Sessions, Flow stores only disabled agent-environment identifiers and the preferred terminal launch mode. It does not persist a session catalog, prompts, previews, working directories, or repository history.

## Resume and external Codex activity

When you resume, Flow validates the directory and starts Windows Terminal with the original Windows or WSL environment.

Codex may independently connect to OpenAI when you use it. That communication is performed by the installed Codex CLI under its own configuration and applicable OpenAI terms and privacy policy. It does not pass through Flow or an Openza service.

## GitHub

GitHub sign-in is optional. OAuth or Personal Access Tokens are stored in Windows Credential Locker and used only for direct requests from Flow to GitHub.

Flow may cache pull request, repository, organization, release, and workflow-run metadata as JSON in its local application-data folder. Signing out removes the saved GitHub credential and username and clears this cache.

Flow does not send GitHub credentials or GitHub data to Openza.

## Settings, background mode, and diagnostics

Flow stores local preferences such as theme, selected GitHub organization, background and notification choices, disabled agent environments, and terminal launch mode.

Background GitHub refresh and Windows notifications are optional. Flow remains usable when they are disabled.

Flow may write a local diagnostic log. It is not uploaded automatically. Review diagnostic files for private paths, account information, repository names, or URLs before sharing them.

## Your controls

You can disable agent environments, avoid selecting a session preview, sign out of GitHub, disable background operation and notifications, or reset or uninstall Flow through Windows Settings.

Deleting or archiving Codex sessions is outside Flow. Use Codex controls for Codex-owned data.

## Sharing

Openza does not sell, rent, license, or share information accessed by Flow with advertisers, data brokers, or other third parties. Flow contains no advertising or behavioral tracking.
