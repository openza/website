Openza Tasks is a simple local-first task app. Capture and finish tasks on your own computer without an account, then add structure, connected apps, or a cloud copy only when they help.

## What you can do

- **Capture quickly.** Add a task with just a title. Projects, labels, and dates are optional.
- **Plan when you want to.** Use Inbox, Next Actions, Today, Calendar, Waiting For, and Someday.
- **Organize your way.** Keep separate Spaces, group work into projects, and tag tasks with labels.
- **Bring connected work together.** Pull in tasks from Todoist and Microsoft To Do, and write completions back.
- **Publish to GitHub.** Turn a task into a GitHub issue and keep the link on the task.
- **Stay recoverable.** Restore points, backup files, and optional OneDrive backups.
- **Script it.** A command-line interface works on the same task database.

## Where it runs

Openza Tasks is available today for **Linux** from the Snap Store. On **Windows**, it is available from the Microsoft Store, and an updated Windows version built on the same app is in progress. **macOS** is planned. See [Install](/tasks/install/).
